一、 系統定位與設計目標
--------------------------------------------------------------------------------
1. 產品定位：
   以 Google Drive / Google Docs 為雲端後端資料源之現代化、零維護成本純前端 PWA
   (Progressive Web App) 花草圖鑑、物種鑑別比對庫與互動知識測驗平台。

2. 核心設計原則：
   - 零依賴與極致效能：純原生 HTML5 / CSS3 / Vanilla JavaScript (ES6+)，無任何肥大前端框架。
   - 雙層本地快取：結合 IndexedDB（大容量存儲）與 localStorage（輕量配置），首屏秒開，完全支援離線使用。
   - 增量雲端同步：透過 Google Apps Script (GAS) 實現「增、修、刪」自動比對與靜默同步，極致節省 API 流量與伺服器資源。
   - 響應式與原生效能：手機、平板、桌機自適應，底層導覽具備深色毛玻璃、質感選取指示與觸控手勢支援。
   - 社群友善與傳播力：內建 HTML5 Canvas 2D 高畫質花草名片海報生成器、URL Deep Link 直連比對與分享。

二、 系統架構與資料流 (Architecture & Data Flow)
--------------------------------------------------------------------------------
1. 雲端資料流：
   [ Google Drive / Google Docs 花草資料庫與鑑別文檔 ]
              │
              ▼ (定時/手動觸發讀取)
   [ Google Apps Script (GAS) Web App API ]
              │ (回傳 JSON 資料流，支援 INCREMENTAL 與 FULL 模式)
              ▼
   [ 前端 sync.js 同步引擎 ]
              │
              ▼
   [ 本地存儲：IndexedDB (plants / comparisons) + localStorage ]
              │
              ▼
   [ 前端控制器：gallery.js / compare.js / quiz.js ] ──> [ 使用者介面 (UI View) ]

三、 核心功能模組技術規格
--------------------------------------------------------------------------------

1. 花草圖鑑展示模組 (Gallery Module - gallery.js)
   - 分頁機制：固定每頁顯示 24 筆 (PAGE_SIZE = 24)，支援平滑翻頁與快速跳轉。
   - 搜尋引擎：支援中文名稱、英文名、學名 (Scientific Name)、別名 (Aliases)、科別 (Family)、形態特徵與照護關鍵字多維度比對。
   - 分類篩選：支援「全部花草」、「🐾 寵物友善」、「科別分類 Chip」（如鳳尾蕨科、天南星科等）。
   - 排序引擎：正向排序（依序號/建檔舊至新）、逆向排序（最新建立在最上方）、隨機打亂排序（Fisher-Yates 洗牌演算法）。
   - 燈箱詳情 (Plant Detail Modal)：
     * 主圖 100% 淨空全顯，背景採用毛玻璃柔焦光暈。
     * 支援鍵盤左右箭頭 (← / →) 與燈箱兩側按鈕無縫切換上一筆 / 下一筆。
     * 分頁標籤切換：植物圖集、基本資料、照護指南、用途與備註、參考資料。
     * 全螢幕大圖模式：點擊大圖進入全黑沉浸式檢視，支援圖片真實比例呈現。
     * 專屬 Deep Link：支援以 `?plant=名稱` 或 `?id=ID` 自動開啟該花草燈箱。

2. 花草名片海報生成器 (Plant Poster Generator - gallery.js)
   - 繪製核心：HTML5 Canvas 2D Context，繪製解析度為高畫質 1080 × 1440 像素。
   - 排版結構：
     * 背景：典雅米白與薄荷微綠漸層底色，搭配雙層微光圓角裝飾線。
     * 頂部 Bar：品牌標誌「🪴 捻花惹草 • 花草圖鑑典藏」與科別。
     * 主圖區：952 × 620 px 圓角裁切，支援 Cover 等比居中縮放與柔和陰影。
     * 品種資訊：中文大字標題 (50px)、英文名、斜體學名、別名列表。
     * 照護膠囊標籤：☀️ 日照需求、💧 水分環境、🐾 寵物安全性評級。
     * 精選摘要框：自動擷取形態重點或照護叮嚀，自適應多行折行並防止溢出。
     * 底部宣告：左側標註品牌與 `@2026 by Famidoc Chang & Antigravity`，右側即時繪製 130x130 px 專屬 QR Code。
   - CORS 容錯防護：多重載入機制，支援 Google Drive 縮圖直連、Weserv.nl 邊緣圖片代理備援，以及離線幾何圖示降級，確保 100% 繪製成功。
   - 匯出支援：
     * 📥 下載 PNG 圖檔至裝置。
     * 📤 調用 Web Share API 原生檔案分享至 LINE / FB / IG。
     * 📋 透過 ClipboardItem API 將圖片二進位 Blob 寫入系統剪貼簿。

3. 相似物種鑑別模組 (Comparison Module - compare.js)
   - 資料結構：支援多物種橫向特徵對照表 (Comparison Matrix Table)。
   - 核心功能：
     * 一句話核心鑑別速記要訣 Banner（突出秒殺辨識特點）。
     * 重點特徵對比矩陣表：左側特徵欄固定，右側物種欄橫向排列。
     * 手機端快速聚焦導覽 Chips：支援「全覽」與個別物種一鍵平滑滾動對齊。
     * 實物特寫卡片圖集：自動匹配鑑別文檔附圖或圖鑑實物照片，點擊放大。
     * 關聯圖鑑速查按鈕：點擊直接跳轉回圖鑑模組並展開該植物詳情。
     * 專屬比對分享連結：支援 `?compare=比對名稱` 自動切換分頁並彈出該筆鑑別。

4. 知識測驗模組 (Quiz Module - quiz.js)
   - 題型機制：每次隨機抽取 5 株不重複植物，題庫動態構建 4 選 1 看圖猜名選擇題。
   - 智能干擾項：自動從現有資料庫抽取 3 株不同物種進行亂數洗牌。
   - 互動回饋：單題即時進度條、每題 20 分、滿分 100 分。
   - 結算機制：測驗結束產生成績評等、答題清單（綠色正確/紅色錯誤標記與正解對照），並可一鍵重新挑戰。

5. 雲端同步與資料持久化 (Sync & Data Module - sync.js, data.js)
   - 本地儲存：IndexedDB Object Stores (`plants`, `comparisons`)。
   - GAS Web App API：
     * 支援 HTTP GET 與 302 跨域重導向。
     * 回傳格式：`{ success: true, syncMode: 'INCREMENTAL', plants: [...], deletedPlants: [...], comparisons: [...], deletedComparisons: [...] }`
     * 增量合併邏輯：依 `id` 建立 Map 索引，保留本機未變更資料，更新異動項，移除刪除項。
   - 管理員權限保護 (Admin Auth)：
     * 設定頁面與手動同步操作均需密碼驗證。
     * 預設管理員密碼雜湊保存於 localStorage，支援自訂變更密碼與鎖定工作階段。

6. PWA 與快取控制 (Service Worker - sw.js)
   - 快取策略：Stale-While-Revalidate（靜態檔案優先快取，背景更新）。
   - 繞過機制：針對 Google Apps Script 與 Google API 請求完全繞過 SW，避免 CORS 轉址中斷。
   - 快取版本控制：每次發布透過版本號字串（如 `v110` / `nian-hua-re-cao-v110`）自動淘汰舊版快取並立即生效。

四、 系統相容性與環境需求
--------------------------------------------------------------------------------
1. 客戶端瀏覽器相容性：
   - iOS / iPadOS：Safari 14+ (支援 PWA「加入主畫面」)
   - Android：Chrome 80+, Samsung Internet, Edge, Firefox
   - Desktop：Chrome, Edge, Safari, Firefox
2. 網路傳輸需求：
   - 支援完整離線瀏覽（離線時使用已下載之快取與 IndexedDB 資料）。
   - 支援弱網環境下背景靜默同步。
3. 託管環境：
   - GitHub Pages (HTTPS 安全連線協議)。
